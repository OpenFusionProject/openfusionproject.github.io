We're announcing the release of OpenFusionLauncher v2.4.1.

This update includes a workaround for a crash on Linux systems with proprietary NVIDIA drivers. This issue always existed, but is now more likely to happen due to updates in the AppImage bundler. As such, we've decided to implement a workaround at runtime that fixes the crash. Users on these systems may notice increased CPU usage from the launcher.

This update also fixes an issue where launcher performance could quickly degrade when many games are launched in parallel. Launcher performance should now be stable in this use case.

Full changelog available [here](https://github.com/OpenFusionProject/OpenFusionLauncher/compare/2.4.0...2.4.1).
